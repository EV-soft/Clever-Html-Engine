# php2html 1.8.1 - API reference

> Generated by `tools/make_api_md.php` from the parameter comments in `php2html.lib.php` - do not edit by hand, run the tool again.
> Written for people **and AI coding assistants**: read this file instead of the 500 KB library.

## Conventions

- **One file:** `require_once 'php2html.lib.php';` - no build step, no package manager. PHP 8.1+.
- **Call with named arguments** - always: `htm_Card_(capt:'@Settings', icon:'fas fa-sliders', clas:'cardW800');`.
  The order of the parameters has changed between versions (1.7); names are stable. An unknown name is a fatal error.
- **Parameter names are 4 characters** from a fixed vocabulary: `labl` label, `capt` caption, `hint` tooltip, `icon` Font Awesome class,
  `name` field name, `valu` value, `form` form id, `acti` action, `wdth` width, `vhgh` max height, `styl` style, `attr` attributes,
  `clas` CSS class, `kind` colour / purpose, `vrnt` variant, `list` options, `plho` placeholder, `rtrn` return instead of echo.
- **Output:** most `htm_*` functions **echo** their HTML. With `rtrn:true` they **return** it as a string instead.
  Functions without `rtrn` always echo (see the table).
- **Texts are translated:** a text that starts with `@` is a translation key - `'@Save'` is shown via `lang()` in the language of the session
  (`$_SESSION['proglang']`, translations in `_trans.sys.json`). Texts without `@` are shown as they are.
- **Pairs:** `htm_Page_` ... `htm_Page_end`, `htm_Card_` ... `htm_Card_end`, `htm_Form_` ... `htm_Form_end`, `htm_Tabs_` / `htm_Tab` ... `htm_Tabs_end`,
  `htm_RowCol_` / `htm_RowCol_next` ... `htm_RowCol_end`, `htm_List_` / `htm_List_item` ... `htm_List_end`. Always close what you open.
- **Session:** the library starts the session (httponly, SameSite=Lax, secure on HTTPS) unless the page has started it already.
- **Forms and CSRF:** `htm_Card_(form:'f_x')` wraps the card body in a POST form **with the CSRF token**. In your own forms echo `csrf_field()`.
  **Every POST is checked when the library is included:** a missing or wrong token stops the request (HTTP 403, *CSRF-validating failed*)
  before your code runs - so the page needs no `csrf_verify()` of its own (calling it again does no harm).
- **Quotes:** `'` for PHP strings, `"` for HTML attributes.

## Pitfalls

- **Several actions in one form:** give each `htm_AcceptButt` its own `valu:` (`valu:'save'`, `valu:'delete'`) and read `$_POST['act']`
  (another name with `name:`). Without `valu` and `acti` the button gets `onclick='location.reload();'` - the form is still posted,
  but the button posts no value of its own.
- **After a POST** answer with `sys_redirect('@Saved')` - not with HTML: the page is loaded again with GET (a reload does not post again)
  and `htm_Page_` shows the message once (`htm_Flash`). An error: `sys_redirect('@Not saved', 'error')`.
- Including the library overwrites the globals `$DocVer`, `$DocRev` and `$©` of the page - copy them to constants **before** the require
  if you need them (the library version is `P2H_VERSION`).
- No nested forms: a card with `form:` must not be inside another card with `form:`.
- A script that must accept a POST **without** a token (a webhook, a JSON API, a callback from another site) must not include the library -
  it would answer 403. Put such endpoints in their own file.
- Global settings are `$gbl_*` variables (colours, card moving, flags, the program root) - set them **before** the require.

## A minimal page

```php
<?php
require_once __DIR__.'/php2html.lib.php';     // starts the session - and stops a POST without a valid CSRF token

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    if (($_POST['act'] ?? '') === 'save')  { /* ... save $_POST['name'] ... */  sys_redirect('@Saved'); }
    if (($_POST['act'] ?? '') === 'reset') { /* ... */                         sys_redirect('@Reset', 'info'); }
    sys_redirect('@Unknown action', 'warning');                  // Post/Redirect/Get: the message is shown by htm_Page_
}

htm_Page_(titl:'My page');
htm_Card_(capt:'@Settings', icon:'fas fa-sliders', form:'f_set', clas:'cardW800');
    htm_Input(labl:'@Name', name:'name', valu:'', wdth:'300px');
    htm_AcceptButt(labl:'@Save',  icon:'fas fa-floppy-disk', kind:'save', form:'f_set', valu:'save');
    htm_AcceptButt(labl:'@Reset', icon:'fas fa-rotate-left', kind:'eras', form:'f_set', valu:'reset');
htm_Card_end();
htm_Page_end();
```
