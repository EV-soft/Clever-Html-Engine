Overview of the PHP files and how they depend on each other  (version 1.6.0)

Your page file (*.page.php)
  must include: php2html.lib.php                 (require_once, after $GLOBALS['gbl_ProgRoot'] and the $need... settings)
   can include: menu.inc.php       - older top menu routines (Menu_Topdropdown, MenuStart...)
                translate.inc.php  - tools for the translation files
                filedata.inc.php   - file / database helpers

php2html.lib.php includes by itself (if the file exists):
  1. The project settings - "early init", right after the library defaults:
       $gbl_InitFile                       (set it in the page BEFORE require_once - a project file outside the library folder)
       else  project.init.php              (next to php2html.lib.php)
     Here: all $gbl_... settings, $gbl_CustomCss, $gbl_CustomLib, $gbl_CustomRules, define('DecimalSep', ...) / ThousandsSep / DEBUG,
           $headEndScript, $bodyEndScript, $gbl_novice, $gbl_CardMove, $gbl_CardResize, $gbl_NotePad, $gbl_SessionWarn ...
  2. Table row rules - inside htm_Table():
       $gbl_CustomRules  else  customRules.inc.php   (next to php2html.lib.php)
  3. Project functions - "late init", at the end of the library:
       $gbl_CustomLib    else  customLib.inc.php     (next to php2html.lib.php)

Data files read by the library (next to php2html.lib.php):
  _trans.sys.json                    - the translations (lang('@...'))
  help_system.json / help_system_<language>.json   - the page help (htm_PageHelp, $gbl_HelpFile)
  manifest.json, favicon.svg         - install as an app (linked by htm_Page_ when they exist)

External libraries (folder _assets/ - or from CDN): set in the page before require_once:
  $needJquery, $needTablesorter, $needPolyfill, $needFontawesome, $needTinymce, $needPdfview   (0: off  1: local  2: CDN  3: auto)

Keep your project files outside the library folder, and an update of the library never overwrites them.
